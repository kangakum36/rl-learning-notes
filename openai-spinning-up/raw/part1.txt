Part 1 - Key Concepts in RL

Intro

* RL is the study of agents and how they learn by trial and error.
* Main characters are agent and environment. Agents get observations at every step and perceive a reward signal which tells it how good or bad the state is.

States and Observations 

* State s is a complete description of the world. Observation o is partial description of state.
* Both represented by real valued vector, matrix, tensor
* Environment is fully observed when agent observes complete state, when only partial observation is partially observed

Action Spaces
Set of valid actions to take, can be discrete (Go) or Continuous (Robot)

Policies

* Policy is a rule used by an agent to decide what actions to take, Can be deterministic or stochastic

$$
a_t = \mu(s_t)
a_t ~ \pi(\dot | s_t)
$$

* Deep RL deals with parameterized policies - outputs are computable functions that depend on a set of parameters which can be adjusted to change behavior via an optimization algorithm. In such policies, parameters are denoted by $\theta$ or $\phi$

$$
a_t = \mu_{\theta}(s_t)
a_t ~ \pi_{\theta}(\dot | s_t)
$$

* KEY KEY KEY - policy **function** is the neural net that outputs the policy parameters. the policy is the set of actions e.g. described by a multivariate gaussian.

Trajectories

* A trajectory $\tau$ is a sequence of states and actions in the world 
$$
\tau = (s_0, a_0, s_1, a_1, ...)
$$

* The very first tate of the world s_0 is randomly sampled from the start-state distribution, denoted by $\rho_0$.

State transitions are governed by natural laws of the environment, and depend only on the most recent action. Can either be deterministic $s_{t + 1} = f(s_t, a_t)$ or stochastic $s_{t + 1} ~ P(\dot | s_t, a_t)$
* FYI for Akum reading this later, the $\dot$ inside the probability is a placeholder for the argument of the funciton, in other words the probability of the next state is sampled from the probability distribution s', which itself is the sampling distribution with some probability given s_t and a_t. In shorthand, $P(s_{t + 1} | s_t, a_t)$, where P is the PDF of the state transition distribution.

Reward and Return
* Reward function R is critically important in RL. Depends on current state of the world, action taken, next state. 
* Agent's goal is to maximize cumulative reward over a trajectory, but this can mean a few things.
* First kind is finite-horizon undiscounted return, which is just the sum of rewards obtained in a fixed window:
$$
R(\tau) = \sum{t = 0}{T}r_t
$$
* Second kind is infinite horizon discounted return, which is sum of all rewards ever obtained, discounted by how far off in the future they are obtained. Discount factor is $\gamma \in (0, 1)$
$$
R(\tau) = \sum{t = 0}{\inf}\gamma^t r_t
$$

* Why discount? Intuition - cash now > cash later. Mathematically, infinite horizon sum may not converge and is hard to deal with in equations. But with a discount factor and under reasonable conditions, inf sum converges.
* Deep RL practice can blur the line a fair bit, for example algos to optimize undiscounted return but using discount factors in estimating value functions (no idea what this means, should ask claude).

The RL problem
* goal of RL is to select a policy which maximizes the expected return when the agent acts according to it.
* If the environment transitions and policy are stochastic, the probability of a T step trajectory is

$$
P(\tau | \pi) = \rho_0(s_0) \prod{t = 0}{T-1}P(s_{t + 1} | s_t, a_t)\pi(a_t, s_t)
$$

* Expected return is
$$
J(\pi) = \int_{\tau}P(\tau | \pi)R(\tau) = \mathbb{E}_{\tau ~ \pi} left[R(\tau)\right]
$$

* Central optimization problem in RL can be expressed by below, with $\pi^*$ being the optimal policy
$$
\pi^* = \argmax_{pi} J(\pi)
$$

Value Functions
* Often useful to know the value of a state or state action pair, in other words the expected return if you start in that state and act according to a particular policy forever. There are 4 main value functions.

1. On policy value function, $V^{pi}(s)$, gives expected return if start in $s$ and always act according to $\pi$
$$
V^{\pi}(s) = \mathbb{E}_{\tau ~ \pi} \left[R(\tau) | s_0 = s\right]
$$

2. On policy action value function, gives expected return if you start in $s$, take arbitrary aciton $a$ (might not come from policy), and then forever act according to $\pi$
$$
Q^{\pi}(s, a) = \mathbb{E}_{\tau ~ \pi} \left[R(\tau) | s_0 = s, a_0 = a\right]
$$

3. Optimal value function, gives expected return if start in s and always act according to optimal policy in env.
$$
V^{*}(s) = \max_{pi}\mathbb{E}_{\tau ~ \pi} \left[R(\tau) | s_0 = s\right]
$$
4. Optimal Action-Value Function, expected return start in s, take arb act a, forever act according to optimal policy.
$$
Q^{*}(s, a) = \max_{pi}\mathbb{E}_{\tau ~ \pi} \left[R(\tau) | s_0 = s, a_0 = a\right]
$$

Two lemmas which just require some algebra to prove:

$$
V^{\pi}(s) = E_{a ~ \pi} \left[Q^{\pi}(s, a)\right]

V^{*}(s) = max_{a} Q^{*}(s, a).
$$

The Optimal Q-Function and the Optimal Action

* By def, Q^{*}(s, a) gives the expected return for starting in $s$, taking (arbitrary) action $a$, and then acting according to optimal policy forever.
* The optimal policy in $s$ will select whichever action maximizes expected return from starting in $s$. So if we have $Q^{*}$, we can directly obtain the optimal action $a^{*}(s)$ via 

$$
a^{*}(s) = \argmax_{a}Q^{*}(s, a)
$$

* Even if there are multiple actions which maximize $Q^*(s, a)$, there is always an optimal policy which deterministically selects an action.

Advantage functions

* Sometimes we want to know how much better an action is than others on average, rather than how good it is in an absolute sense. 
* The advantage function $A^{\pi}(s, a)$ corresponding to a policy $\pi$ describes how much better it is to take a specific action $a$ in state $s$, over randomly slecting an action according to $\pi(\dot | s)$, assuming you act according to $\pi$ forever after. Mathematically we write:

$$
A^{\pi}(s, a) = Q^{\pi}(s, a) - V^{\pi}(s)
$$
